# SauceDemo UI Tests – Selenium + Cucumber (Java)

[![UI tests](https://github.com/Mohinilatha31/saucedemo-selenium-cucumber/actions/workflows/tests.yml/badge.svg)](https://github.com/Mohinilatha31/saucedemo-selenium-cucumber/actions/workflows/tests.yml)

Automated end-to-end tests for the demo web shop [saucedemo.com](https://www.saucedemo.com), written as
readable Gherkin scenarios (BDD) and implemented with Selenium WebDriver, Java and JUnit 5.

## What is tested

| Feature | Scenarios |
|---|---|
| Login | Valid login; rejected logins (locked-out user, wrong password, missing username) as a Scenario Outline |
| Shopping cart | Add one product, add two products, cart badge count and cart contents |
| Checkout | Complete an order end to end; validation error when the postcode is missing |

8 scenarios in total. Scenarios tagged `@smoke` form a quick smoke suite.

## How it is built

- **Page Object Model** – each page (`LoginPage`, `InventoryPage`, `CartPage`, `CheckoutPage`) owns its locators and actions, so tests read like user behaviour and a UI change is fixed in one place
- **Explicit waits** in `BasePage` (no `Thread.sleep`) for stable tests
- **Hooks** close the browser after every scenario and attach a screenshot to the report when a scenario fails
- **Selenium Manager** downloads the right ChromeDriver automatically
- **HTML report** generated by Cucumber after every run
- **CI with GitHub Actions** runs the suite automatically on every push

```
src/test/
├── java/com/latha/saucedemo/
│   ├── RunCucumberTest.java      # JUnit 5 suite that runs all features
│   ├── pages/                    # Page Object Model
│   ├── steps/                    # Step definitions (Gherkin -> Java)
│   └── support/                  # Browser setup and hooks
└── resources/
    ├── features/                 # login, cart, checkout .feature files
    └── junit-platform.properties # Cucumber settings and report output
```

## Run the tests

Requirements: Java 21+, Maven (bundled with IntelliJ IDEA), Google Chrome.

```bash
mvn test                              # all scenarios, Chrome visible
mvn test -Dheadless=true              # without opening a browser window
mvn test -Dcucumber.filter.tags=@smoke   # smoke suite only
```

In IntelliJ: open `RunCucumberTest.java` and click the green run arrow.

**Continuous integration:** every push to `main` runs all scenarios on GitHub Actions in headless Chrome (`.github/workflows/tests.yml`). The badge at the top shows the latest result, and the Cucumber HTML report is saved with each run.

Report: open `target/cucumber-report.html` in a browser after a run.
